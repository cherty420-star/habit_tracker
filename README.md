# Habit Tracker API

API для трекера полезных привычек по книге «Атомные привычки» Джеймса Клира.

## Функциональность

- Регистрация и JWT авторизация пользователей
- CRUD операции для привычек
- Пагинация (5 привычек на страницу)
- Валидация привычек:
  - Время выполнения не больше 120 секунд
  - Нельзя одновременно указать вознаграждение и связанную привычку
  - У приятной привычки не может быть вознаграждения
  - Периодичность не реже 1 раза в 7 дней
- Публичные привычки (доступны всем для просмотра)
- Telegram бот для уведомлений
- Celery для отложенных задач
- Swagger/ReDoc документация

## Технологии

- Django 4.2
- Django REST Framework
- JWT авторизация
- Celery + Redis
- SQLite/PostgreSQL
- Telegram Bot API
